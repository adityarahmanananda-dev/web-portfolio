Cornell — Catatan

• C adalah compiled language (source → binary via compiler)
• Stack: LIFO, otomatis; Heap: manual (malloc/free)
• Pointer menyimpan alamat memori
• Array adalah pointer ke elemen pertama
• String = char[] diakhiri '\0'

Cornell — Ringkasan

Memahami model memori (stack/heap) dan pointer adalah fondasi untuk data structures & CS50 problem sets.

Memory Model

├─ Data (globals/static)

│ └─ pointer management
